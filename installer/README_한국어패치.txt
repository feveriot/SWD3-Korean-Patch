헌원검 3: 구름과 산의 저편 (Steam판) 한국어 패치 v1.2

[설치]
1. 이 압축 파일을 게임 폴더에 풉니다. (swd3.exe가 있는 폴더)
   예: ...\steamapps\common\SWD3
2. KoreanPatch_Install.bat 을 실행합니다. (이전 버전 위에 그대로 덮어 설치해도 됩니다)
3. 게임 실행 전 언어를 English로 설정합니다.

[제거]
KoreanPatch_Uninstall.bat 실행 (설치 때 만든 백업으로 되돌림)
백업이 없으면 Steam의 '게임 파일 무결성 확인'을 사용하세요.

[내용]
- 대사·아이템·인물/지명·전투 문구 (Mods\swd3_ko.ssmod)
- 그림으로 된 메뉴 한글화: 타이틀 메뉴, 시스템 버튼, 메뉴 막대, 각종 탭·버튼, 신마이사록 분류 라벨, 상점 머리줄, 저장/불러오기 화면 제목
- 메뉴·상태창 문자열 (en\StringDB.txt)
- 한글 글꼴: 본명조 Noto Serif KR Medium (SIL Open Font License 1.1, KoreanPatch\License 참고)
- 편의 기능 (Mods\swd3_ko_qol.ssmod) — 게임 중 단축키
    F4  설정표 계속 보이기/숨기기 (F5~F8을 누르면 3초간 표시)
    F5  필드 전투 확률: 보통 → 2배 → 4배 → 끔
    F6  이동 속도: 보통 → 1.5배 → 2배 (다음 맵 이동부터 적용)
    F7  전투 획득 돈: 보통 → 2배 → 4배
    F8  전투 획득 경험치: 보통 → 2배 → 4배
  설정은 세이브 파일에 같이 저장됩니다. 쓰지 않으려면 게임의 MOD 관리에서 SWD3 Korean QoL을 끄세요.
- 중문 번체 원문 기준 번역.
